# Dependencies for continuous integration.
#
# The default test suite runs against OCR_PROVIDER=stub, which loads no model
# and never imports PaddleOCR - tests/test_provider_isolation.py enforces that.
# So CI deliberately installs the service WITHOUT paddlepaddle/paddleocr:
# it keeps runs fast and removes a large, platform-sensitive wheel from the
# critical path of every pull request.
#
# The integration suite (tests/integration) skips itself automatically when the
# engine is absent, so nothing is silently passed over - those tests are marked
# `integration` and are meant to run on the target server.
#
# Full runtime dependencies live in requirements.txt.
